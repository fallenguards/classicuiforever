# Changelog

All notable changes to ClassicUI Forever: Standalone Damage Meter Skins are documented here. It has version numbers of its own, apart from the full ClassicUI Forever's.

## [1.0.2] - 2026-11-04

### Changed
- On Forever, a chat line at login thanks you for playing on the new client and links the page to report bugs, so they get fixed as soon as possible.

## [1.0.1] - 2026-11-03

### Changed
- The size box in Default toggles' confirm names the game's UI Scale and the percent it sets.

## [1.0.0] - 2026-10-29

### Added
- First release: the game's own damage meter in the 1.x look from ClassicUI Forever, as an addon of its own.
