# Changelog

All notable changes to ClassicUI Forever: Standalone Nameplates are documented here. It has version numbers of its own, apart from the full ClassicUI Forever's.

## [1.0.0] - 2026-10-29

### Changed
- Version numbers of its own from now on, starting at 1.0.0. Earlier files carried the full addon's numbers (0.40.5).
- The settings window has a search box.

### Fixed
- The welcome note (right-click the minimap button) is about this addon; it described the full addon's action bars and bags.
