# Changelog

All notable changes to ClassicUI Forever: Standalone Windows and Menus are documented here. It has version numbers of its own, apart from the full ClassicUI Forever's.

## [1.0.0] - 2026-11-17

### Added
- First release: the windows and menus from ClassicUI Forever as an addon of its own. The 1.x character sheet, spellbook, talents, quest log and tracker, professions and social windows, and the game's own windows, menus and tooltips in 1.x frames. Your edit mode layout and interface size stay as they are.
